## 1. Red-Team Attack Evaluation Matrix

Every scenario is formally classified according to the mandatory B0 evidence taxonomy:
- **`ARCHITECTURALLY MITIGATED — IMPLEMENTATION UNVERIFIED`**: Architectural control is designed and specified; implementation is planned and gated for verification in B1–B5.
- **`VERIFIED AGAINST EXISTING PERSONAL OS INFRASTRUCTURE`**: Reused platform capability proven in certified Personal OS baseline (Phase 0–8).
- **`OPEN GAP`**: Requires architectural decision before B0 freeze.
